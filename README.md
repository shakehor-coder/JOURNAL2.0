# Journal 2.0 • Компьютерная Академия ТОП

Улучшенная версия платформы электронного дневника [journal.top-academy.ru](https://journal.top-academy.ru) с аутентичным дизайном, входом по QR-коду, видеозвонками, интерактивной доской и онлайн-песочницей кода.

---

## 🚀 Быстрый запуск

### Вариант 1 (В один клик на Windows):
- **`run.bat`** — запуск сервера в режиме продакшн на **http://localhost:5000** и автооткрытие браузера.
- **`dev.bat`** — запуск в режиме разработки с горячей перезагрузкой (Vite порт 3000 + бэкенд 5000).

### Вариант 2 (Через терминал):
```bash
# Установка зависимостей и сборка всего проекта:
npm run build

# Запуск сервера:
npm start
```
После этого откройте в браузере: [http://localhost:5000](http://localhost:5000)

## 🌐 Бесплатный запуск на сервере (Хостинг)

Подробная пошаговая инструкция с описанием шагов находится в файле **[DEPLOYMENT.md](DEPLOYMENT.md)**.

### Рекомендуемый хостинг — **Render.com** (Бесплатный тариф):
1. Загрузите проект в ваш репозиторий на **GitHub**.
2. В личном кабинете **Render.com** нажмите **New +** -> **Web Service**.
3. Подключите репозиторий и укажите:
   - **Build Command**: `npm run build`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free`
4. Через 2 минуты сервис будет доступен по бесплатному адресу с поддержкой HTTPS и WebSockets (например: `https://journal-top-academy.onrender.com`).

Также проект содержит готовый **`Dockerfile`** и конфигурационный файл **`render.yaml`** для развертывания на Railway, Koyeb, Fly.io или любом VPS.

## 🌟 Основные возможности

1. **Официальный дизайн Академии ТОП**:
   - Аутентичная цветовая гамма (`#f4f6fb`, белоснежные карточки, электрик-синий `#1877F2`, акценты `#6C59F5`).
   - Бейджи баллов, коинов (StepCoins) и кристаллов.
   - Светлая аккуратная тема по умолчанию и поддержка тёмной темы.

2. **Вход по QR-коду (WhatsApp / MyStat style)**:
   - Синхронизация в реальном времени через WebSockets (Socket.io).
   - Динамический расчет адреса авторизации (работает как локально, так и на облачных доменах).
   - Таймер жизни кода (5 минут).
   - Кнопка симуляции сканирования для быстрого тестирования без смартфона.
   - Резервный вход по логину/паролю и демо-режим.

3. **Встроенные видеозвонки и аудитории (Jitsi Meet SFU)**:
   - Высокостабильные аудио- и видеозвонки (HD качество).
   - Демонстрация экрана в 1 клик (Screen Sharing) без зависаний.
   - Индикатор активности голоса, шумоподавление, чат аудитории и поднятие руки.
   - Отдельные виртуальные аудитории по группам (9/3-РПО, 9/1-РПО, ГД 9/1 и др.).

4. **Электронная интерактивная доска (Whiteboard)**:
   - Бесконечный холст, рисование от руки с плавной интерполяцией линий.
   - Геометрические фигуры (прямоугольники, круги, стрелки, линии).
   - Синхронизация с сервером: вновь подключившиеся участники сразу видят текущий рисунок (`board-init-state`).
   - Палитра цветов, ластик, очистка холста и экспорт в PNG.

5. **Песочница кода (Stepik / Monaco runner)**:
   - Написание JavaScript кода в браузере.
   - Автоматический изолированный прогон по тест-кейсам с проверкой безопасности и вывод вердикта.

6. **Разделы дневника**:
   - Расписание занятий на неделю (с фильтрами по типам: лекции, лаборатории, практикумы).
   - Домашние задания (с фильтрами по статусам и формой отправки решений).
   - Успеваемость и оценки (12-балльная шкала, возможность добавления оценок).
   - Рейтинг студентов группы.
   - Настройки с возможностью подключения живого API-токена Академии ТОП (`msapi.top-academy.ru`).

## 🛠 Стек технологий
- **Backend**: Node.js, Express, Socket.io, QRCode, Axios
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Canvas API, Jitsi Meet SFU API
